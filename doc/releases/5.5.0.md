## What's Changed

### Bug fixes (plugins)

- [Kobo E-Reader Dictionary](/doc/p/kobo.md) writer: support generating Japanese dictionaries (single-character prefix generation), PR [#740](https://github.com/ilius/pyglossary/pull/740), [#741](https://github.com/ilius/pyglossary/pull/741) by [@kylefeng28](https://github.com/kylefeng28)

- [Wiktextract](/doc/p/wiktextract.md) reader: fix a warning about `*_offsets` example keys, [#733](https://github.com/ilius/pyglossary/issues/733)

- [EPWING](/doc/p/epwing.md) reader: fix reader parsing, PR [#744](https://github.com/ilius/pyglossary/pull/744) by [@sashi0034](https://github.com/sashi0034)

- [PocketBook SDIC](/doc/p/pocketbook_sdic.md) writer: prevent crashing when an entry exceeds the maximum encodable size, PR [#746](https://github.com/ilius/pyglossary/pull/746) by [@Tiger-222](https://github.com/Tiger-222)

- [XDXF](/doc/p/xdxf.md) and [StarDict](/doc/p/stardict.md) readers: fix XDXF rendering issues by refactoring the transformer using a state machine and disabling `xsl` mode, issues [#532](https://github.com/ilius/pyglossary/issues/532), [#562](https://github.com/ilius/pyglossary/issues/562)

### Bug fixes (user interface)

- Bug fix in `ui_gtk3` and `ui_gtk4`: fatal error when `FileSizeOption` has an empty or non-integer value, [#735](https://github.com/ilius/pyglossary/issues/735)

### Features

#### New read/write format functionalities

- Reader for **[Dict.cc translation exports](/doc/p/dict_cc_source.md)** — [Dict.cc](https://en.wikipedia.org/wiki/Dict.cc) (tab-separated source file).

- [PocketBook SDIC](/doc/p/pocketbook_sdic.md) writer: support custom metadata through `metadata.json`, PR [#745](https://github.com/ilius/pyglossary/pull/745) by [@Tiger-222](https://github.com/Tiger-222)

#### New user interface features

- Add `ui_slint`, PR [#732](https://github.com/ilius/pyglossary/pull/732) by [@glowinthedark](https://github.com/glowinthedark)
