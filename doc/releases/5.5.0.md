## What's Changed

### Bug fixes (plugins)

- [Kobo E-Reader Dictionary](/doc/p/kobo.md): suppport generating Japanese dictionaries (single char prefix generation), PR [#740](https://github.com/ilius/pyglossary/pull/740), [#741](https://github.com/ilius/pyglossary/pull/741) by [@kylefeng28](https://github.com/kylefeng28)
- [Wiktextract](/doc/p/wiktextract.md): fix warning for `*_offsets` example keys, [#733](https://github.com/ilius/pyglossary/issues/733)

### Bug fixes (user interface)

- Bug fix in `ui_gtk3` and `ui_gtk4`: fatal error on `FileSizeOption` with empty or non-int value, [#735](https://github.com/ilius/pyglossary/issues/735)

### Features

#### New read/write format functionalities

- **[Anki deck package](/doc/p/anki_apkg.md)** reader — [exporting.html](https://docs.ankiweb.net/exporting.html) (.apkg, .colpkg).
- **[Dict.cc translation export](/doc/p/dict_cc_source.md)** reader — [Dict.cc](https://en.wikipedia.org/wiki/Dict.cc) (tab-separated source file).

#### New user interface features

- Add `ui_slint`, PR [#732](https://github.com/ilius/pyglossary/pull/732) by [@glowinthedark](https://github.com/glowinthedark)
