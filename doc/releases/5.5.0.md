## What's Changed

### Compatibility changes

- Remove the `ayandict_sqlite` reader/writer from the supported plugins; the code is now kept under `pyglossary/exp/ayandict_sqlite/`
- Remove the `--reverse` option and glossary reverse feature, along with the reverse-related configuration keys and UI parameters
- [ZIM](/doc/p/zim.md) reader now requires `libzim>=4.0`, using the public `Archive.get_entry_by_id` API. Upgrade with `pip install "libzim>=4.0"`

### Bug fixes (plugins)

- [Kobo E-Reader Dictionary](/doc/p/kobo.md) writer: support generating Japanese dictionaries (single-character prefix generation), PR [#740](https://github.com/ilius/pyglossary/pull/740), [#741](https://github.com/ilius/pyglossary/pull/741) by [@kylefeng28](https://github.com/kylefeng28)

- [Wiktextract](/doc/p/wiktextract.md) reader: fix a warning about `*_offsets` example keys, [#733](https://github.com/ilius/pyglossary/issues/733)

- [EPWING](/doc/p/epwing.md) reader: fix reader parsing, PR [#744](https://github.com/ilius/pyglossary/pull/744) by [@sashi0034](https://github.com/sashi0034)

- [PocketBook SDIC](/doc/p/pocketbook_sdic.md) writer: prevent crashing when an entry exceeds the maximum encodable size, PR [#746](https://github.com/ilius/pyglossary/pull/746) by [@Tiger-222](https://github.com/Tiger-222)

- [XDXF](/doc/p/xdxf.md) and [StarDict](/doc/p/stardict.md) readers: fix XDXF rendering issues by refactoring the transformer using a state machine and disabling `xsl` mode, issues [#532](https://github.com/ilius/pyglossary/issues/532), [#562](https://github.com/ilius/pyglossary/issues/562)

- [DSL](/doc/p/dsl.md) reader: prevent the title from being overwritten by an abbreviation file (`_abrv.dsl`) or `#INCLUDE`, PR [#750](https://github.com/ilius/pyglossary/pull/750) by [@glowinthedark](https://github.com/glowinthedark)

- [EPUB2](/doc/p/epub2.md) writer: point table-of-contents entries at their own group pages, PR [#755](https://github.com/ilius/pyglossary/pull/755) by [@wleeaf](https://github.com/wleeaf)

- [EPUB2](/doc/p/epub2.md) writer: escape terms and plain text definitions, PR [#756](https://github.com/ilius/pyglossary/pull/756) by [@wleeaf](https://github.com/wleeaf)

- [QuickDic6](/doc/p/quickdic6.md) reader: avoid hitting the recursion limit on deep index chains, [#675](https://github.com/ilius/pyglossary/issues/675)

- [QuickDic6](/doc/p/quickdic6.md) reader: handle malformed stop-list sizes in older DictionaryPC files and replace invalid surrogate character references with U+FFFD, [#675](https://github.com/ilius/pyglossary/issues/675)

### Bug fixes (user interface)

- Bug fix in `ui_gtk3` and `ui_gtk4`: fatal error when `FileSizeOption` has an empty or non-integer value, [#735](https://github.com/ilius/pyglossary/issues/735)

### Features

#### New read/write format functionalities

- Reader and writer for **[Wudict Markdown](/doc/p/wudict_md.md)** (`.wudict.md`) — regular Markdown with GFM tables, plus the small header block used by the [wudict](https://github.com/wuweidict/wudict) dictionary app. The reader processes the file in chunks to handle very large dictionaries. PR [#751](https://github.com/ilius/pyglossary/pull/751), [#754](https://github.com/ilius/pyglossary/pull/754) by [@glowinthedark](https://github.com/glowinthedark)

- Reader for **[Dict.cc translation exports](/doc/p/dict_cc_source.md)** — [Dict.cc](https://en.wikipedia.org/wiki/Dict.cc) (tab-separated source file).

- [PocketBook SDIC](/doc/p/pocketbook_sdic.md) writer: support custom metadata through `metadata.json`, PR [#745](https://github.com/ilius/pyglossary/pull/745) by [@Tiger-222](https://github.com/Tiger-222)

#### New user interface features

- Add `ui_slint`, PR [#732](https://github.com/ilius/pyglossary/pull/732) by [@glowinthedark](https://github.com/glowinthedark)
