# WordNet test subset

This directory is a small synthetic subset of the Princeton WordNet 3.1 lexical
database, prepared only as a fixture for PyGlossary's WordNet reader tests.
Entries are shortened and sampled from the original data.

Original dictionary: WordNet 3.1, a lexical database for English, by the
Princeton University Cognitive Science Laboratory. Copyright 2011 by Princeton
University. All rights reserved.

WordNet is distributed under the WordNet license. A copyright and license
notice is included in the header of each file in this directory. See
https://wordnet.princeton.edu/ for the original project and its license.

Only the `data.*` files and `index.noun` (needed for copyright metadata) are
included. The other index and exception files are omitted to keep the fixture
small.

This subset is not published by, maintained by, or endorsed by Princeton
University. It is not a complete or usable copy of WordNet; entries were
selected to exercise the PyGlossary WordNet reader.
